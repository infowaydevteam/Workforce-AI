IWF Monitoring Agent Update Demo

Standup goal: show that employees install the monitoring agent once, then new agent versions are distributed through backend manifest based auto-update.

Windows package ready macOS package ready Checksum verified by agent Online / Idle / Offline preserved

Demo Flow

1

Admin creates employee

System generates an agent_token for that employee.

2

Employee downloads agent

The token download page offers Windows and macOS packages.

3

Installer writes config

Installer writes token and API base URL, then starts the agent.

4

Agent runs in background

Agent reports Online, Idle, or Offline.

5

Auto-update

Agent checks manifest, downloads package, validates SHA256, applies update, and restarts.

Talk Track

"Before this work, every new agent feature required employees to uninstall and reinstall. Now we publish a versioned package and update the manifest. Existing agents detect the new version, download the right platform package, verify checksum, and apply it without employee reinstall."

"This is not instant code push. We still do a release. The improvement is that the release is distributed by the agent automatically."
